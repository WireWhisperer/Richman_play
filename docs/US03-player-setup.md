# US03 玩家设置

## 明确需求

- 启动后选择 2～4 名玩家。
- 角色编号固定为：1 钱夫人、2 阿土伯、3 孙小美、4 金贝贝。
- 角色不能重复。
- 颜色和标识固定为：红色 Q、绿色 A、蓝色 S、黄色 J。
- 选择顺序就是 `Game.players` 数组顺序和后续游戏顺序。
- 非法输入需要重新提示，且不能错误修改游戏状态。

## 接口边界

- `player_setup_run`：命令行交互入口。
- `player_setup_apply_sequence`：自动化测试入口，接受 `12`、`31` 等紧凑序列。
- `player_setup_print_summary`：按游戏顺序输出确认列表。
- `player_setup_character`：唯一角色编号、名称、颜色和标识映射。

US03 不负责初始资金、地图加载、掷骰子或其他 Story 的业务逻辑。

## 测试矩阵

| 输入/场景 | 预期结果 |
| --- | --- |
| `12` | Q、A；玩家数 2 |
| `31` | S、Q；顺序保持 |
| `1234` | 支持 4 名玩家 |
| `1` / `12341` | 玩家数量非法，状态不变 |
| `11` | 拒绝重复角色，状态不变 |
| `1235` | 角色编号非法，状态不变 |
| `1#2` | 非数字字符非法，状态不变 |
| CLI 非法后重输 | 显示明确提示并完成正确设置 |
| CLI 提前 EOF | 返回 I/O 错误，状态不变 |
